# Squirrel browser extension

A minimal popup for Chrome, Edge, Brave and Firefox: paste a link (it starts with the page you're
on), pick a format, and the file is saved to the Squirrel desktop app's download folder.

The extension can't run yt-dlp itself, so it needs the **Squirrel app for Mac or Windows**
installed and opened once. The app registers its download engine with your browsers through
[native messaging](https://developer.mozilla.org/docs/Mozilla/Add-ons/WebExtensions/Native_messaging)
each time it starts. After that, the app doesn't need to be open. Downloads keep going after the
popup closes.

## Install

The Chrome Web Store and Firefox Add-ons don't list YouTube downloaders, so install it yourself:

**Chrome, Edge, Brave:** open `chrome://extensions` (or `edge://extensions`), turn on
**Developer mode**, click **Load unpacked**, and choose this `extension` folder (unzip
`Squirrel-extension.zip` from the releases page first). The key in `manifest.json` gives it the
fixed ID `hdacmehgeiecekdneiggfemjeolmdfbc`, which the desktop apps allow.

**Firefox (140+):** release versions of Firefox only install signed add-ons. Sign it once as an
unlisted (self-distributed) add-on on [addons.mozilla.org](https://addons.mozilla.org/developers/):

```bash
npx web-ext sign --source-dir extension --channel unlisted --api-key … --api-secret …
```

Then open the signed `.xpi` in Firefox. To try it without signing, use `about:debugging` ›
**This Firefox** › **Load Temporary Add-on** and pick `manifest.json` (it's removed when Firefox
restarts).

## Files

- `manifest.json`: Manifest V3, valid in both browsers (Chrome uses `service_worker`, Firefox uses
  `scripts`)
- `background.js`: holds the connection to the engine and runs downloads
- `popup.html`, `popup.css`, `popup.js`: the popup
- `icons/`: generated by `branding/render_icons.py`

If you change the extension's ID (for example, after publishing it to a store), add the new ID to
`desktop/macos/App/Sources/NativeMessaging.swift` and
`desktop/windows/src/main/kotlin/com/natan/squirrel/NativeMessaging.kt`.
